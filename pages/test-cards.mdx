## Transação aprovada

Para testar uma transação aprovada, utilize um dos números abaixo, qualquer código de segurança com 3 dígitos e qualquer data de validade igual ou até quinze anos à frente.

<Tabs>
  <Tab title="Mastercard">
    | Número do Cartão |
    | ---------------- |
    | 5555 5555 5555 5557 |
  </Tab>
  <Tab title="Visa">
    | Número do Cartão |
    | ---------------- |
    | 4444 4444 4444 4448 |
  </Tab>
</Tabs>

## Transação rejeitada

Para simular uma transação rejeitada, utilize qualquer outra numeração válida de acordo com o algoritmo de Luhn. Exemplos:
