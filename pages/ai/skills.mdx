A **Parcele+ Skills** é um conjunto de **conhecimentos estruturados**, **regras técnicas** e **exemplos práticos** projetados para ensinar agentes de IA e desenvolvedores a integrar corretamente com o ecossistema Parcele+.

Funciona como um **manual inteligente e executável** — focado em reduzir ambiguidade, evitar erros comuns e acelerar integrações reais, especialmente em ambientes assistidos por IA.

## O que são Skills?

Skills são **pacotes de contexto especializado** que descrevem:

- Regras de negócio do Parcele+ (status de pedido, simulação, desembolso)
- Padrões técnicos oficiais da API
- Convenções de código por linguagem (uma regra por SDK)
- Boas práticas para autenticação, webhooks e segurança

Elas podem ser consumidas por **IDEs** e **ferramentas de AI coding** como Cursor, Claude Code e similares.

## Como instalar

<Steps>
  <Step title="Clone o repositório">
    ```bash
    git clone https://github.com/Twila-Digital/twila-parcelemais-skills
    ```
  </Step>

  <Step title="Adicione ao contexto da IA">
    Inclua a pasta do repositório no contexto do seu editor.

    **Cursor:** adicione o caminho em `.cursorrules` ou workspace rules.

    **Claude Code:** referencie na configuração do projeto.

    **Skill única:** se sua ferramenta só aceita um arquivo, use `SKILL-CONSOLIDATED.md` (tudo concatenado) ou `SKILL-AGENT.md` (só o modo de API direta via `curl`).
  </Step>
</Steps>

## Filosofia

As Parcele+ Skills seguem os mesmos princípios dos SDKs oficiais:

- **Explícitas** — sem regras implícitas ou achismos
- **Auditáveis** — texto claro, versionado e revisável
- **Modulares** — cada skill resolve um problema específico
- **IA-first** — escritas pensando em consumo automático
