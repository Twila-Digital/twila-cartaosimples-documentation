## Quando usar

As Skills servem pra dois momentos diferentes:

| | Integration Mode | Agent Mode |
|---|---|---|
| **Objetivo** | Gerar código de integração correto | Executar ações direto na API via `curl` |
| **Ideal para** | IDEs com AI coding (Cursor, Claude Code) escrevendo um SDK | Automações, assistentes, agentes operando a API sem escrever código |
| **Formato** | Arquivos de contexto lidos pelo editor (`rules/`, `examples/`) | `rules/agent.md` / `SKILL-AGENT.md` |
| **Requer credenciais** | Não (só pra rodar o código gerado) | Sim (`ClientId`/`ClientSecret`) |
