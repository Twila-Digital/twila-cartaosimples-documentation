## Para quem é cada ferramenta

| | MCP Server | Skills |
|---|---|---|
| **Objetivo** | Executar ações na API via IA | Fornecer contexto pra IA gerar código correto |
| **Ideal para** | Automações, assistentes, agentes | IDEs com AI coding (Cursor, Claude Code) |
| **Formato** | Ferramentas MCP chamadas em runtime | Arquivos de contexto lidos pelo editor |
