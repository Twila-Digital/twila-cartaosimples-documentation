---
title: 'Listar webhooks'
openapi: "GET /v1/webhooks"
---

Retorna a lista de webhooks cadastrados pelo parceiro identificado automaticamente pelo token — sem paginação, já que um parceiro tem no máximo 3 webhooks (um por tipo).

## Tipos de webhook

| Valor | Tipo | Disponibilidade |
| --- | --- | --- |
| `1` | **Cliente** | 🟡 **Em roadmap** — pode ser cadastrado, mas ainda não envia notificações. |
| `2` | **Simulação** | 🟡 **Em roadmap** — pode ser cadastrado, mas ainda não envia notificações. |
| `3` | **Pedido** | 🟢 **Disponível** — envia notificações para os eventos de pedido suportados. |

<Warning>
  Os tipos Cliente (`1`) e Simulação (`2`) podem aparecer na listagem, mas ainda não enviam notificações. Atualmente, apenas o tipo Pedido (`3`) está disponível para os eventos suportados.
</Warning>

## Tipos de autenticação

| Valor | Significado |
| --- | --- |
| `1` | **Nenhuma** — a requisição é enviada sem credencial de autenticação. |
| `2` | **Basic** — utiliza a credencial informada para autenticação HTTP Basic. |
| `3` | **JWT** — utiliza a credencial informada como token Bearer JWT. |

<Note>
  Por segurança, as credenciais de autenticação nunca são retornadas por este endpoint.
</Note>
