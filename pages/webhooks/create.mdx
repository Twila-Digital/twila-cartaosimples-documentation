---
title: 'Criar webhook'
openapi: "POST /v1/webhooks"
---

Cria uma configuração de webhook para o parceiro identificado automaticamente pelo token de acesso.

## Tipos de webhook

| Valor | Tipo | Disponibilidade |
| --- | --- | --- |
| `1` | **Cliente** | 🟡 **Em roadmap** — pode ser cadastrado, mas ainda não envia notificações. |
| `2` | **Simulação** | 🟡 **Em roadmap** — pode ser cadastrado, mas ainda não envia notificações. |
| `3` | **Pedido** | 🟢 **Disponível** — envia notificações para os eventos de pedido suportados. |

<Warning>
  Os tipos Cliente (`1`) e Simulação (`2`) podem ser configurados, mas ainda não enviam notificações. Atualmente, apenas o tipo Pedido (`3`) está disponível para os eventos suportados.
</Warning>

## Tipos de autenticação

| Valor | Significado |
| --- | --- |
| `1` | **Nenhuma** — a requisição é enviada sem credencial de autenticação. |
| `2` | **Basic** — utiliza a credencial informada para autenticação HTTP Basic. |
| `3` | **JWT** — utiliza a credencial informada como token Bearer JWT. |

<Note>
  A credencial é obrigatória para Basic e JWT. Pode existir apenas um webhook de cada tipo por parceiro.
</Note>

## Chave de assinatura

A resposta traz `chaveAssinatura`, usada para verificar a autenticidade das notificações recebidas. Ela é exibida **apenas nesta resposta** — guarde-a com segurança, pois não é possível consultá-la novamente. Consulte [Webhooks → Verificando a assinatura](/webhooks#verificando-a-assinatura).
